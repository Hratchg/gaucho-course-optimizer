## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, border widths |
| sm | 8px | Between keyword tags, between RMP stat items, chart margins |
| md | 16px | Card internal padding, sidebar padding, section gaps |
| lg | 24px | Between professor cards, page content padding |
| xl | 32px | Sidebar width internal padding, major layout gaps |
| 2xl | 48px | Page vertical padding on desktop |
| 3xl | 64px | Not used in Phase 3 |

Exceptions:
- Touch targets (mobile): minimum 44px height/width for all interactive elements — applies to slider thumbs, expand toggle button, "Adjust weights" button, Command input, and sentiment badge tap areas. (Source: UI-09)
- Sidebar width: 256px (64 × 4) on desktop — fixed, not fluid. (Source: D-05, RESEARCH.md discretion recommendation)
- Colored left border strip on professor cards: 4px (= xs) — the score color band. (Source: RESEARCH.md Pattern 7)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Card body text, RMP stats, comment text, slider labels |
| Label | 12px | 500 (medium) | 1.4 | Keyword tags, VADER badge text, chart axis labels, stat captions |
| Heading | 20px | 600 (semibold) | 1.2 | Professor name on card, page section headings |
| Display | 28px | 700 (bold) | 1.1 | Gaucho Score number (prominent on card per D-01) |

Notes:
- Exactly 4 sizes declared. No other sizes may be introduced without amending this contract.
- Exactly 2 primary weights in use for body/label content: 400 and 600. Weight 500 applies only to badge/tag labels; weight 700 applies only to the score display — treat both as approved exceptions.
- The Gaucho Score display uses Display size (28px) + Bold (700) because D-01 requires it to be "prominent" — it is the primary decision-making signal on the card.

## Interaction Contract

### Autocomplete (UI-01)

- Component: shadcn/ui `Command`
- Fires query: when input value length >= 2 characters
- TanStack Query key: `['courses', 'search', query]`
- Endpoint: `GET /courses/search?q={query}`
- Keyboard navigation: arrow up/down to move through results, Enter to select
- Selection action: navigate to `/courses/{courseId}` via React Router
- No explicit debounce timer required — TanStack Query deduplicates on the same key; add `useDebounce(value, 300)` if network tab shows per-keystroke requests

### Weight Sliders (UI-07)

- Slider range: 0–10, step 1, integer values only
- Default weights: GPA = 4, Quality = 3, Difficulty = 2, Sentiment = 1 (mirrors Streamlit prototype proportions)
- On change: call `normalizeWeights()` then `computeGauchoScore()` for each professor using stored raw factors — zero API calls
- Re-sort professor list via `useMemo` watching `[professors, weights]`
- State lives at `CoursePage` level, passed down to `WeightSliders` and the card list

### Cold-Start UX (UI-11)

- Show `SkeletonCard` components immediately when `isLoading === true`
- After 3 seconds with `isLoading` still true: show banner "Waking up the server… (free-tier cold start may take 15–30 seconds)"
- Banner dismisses automatically when `isLoading` becomes false
- Implementation: `useColdStartMessage(isLoading)` hook using `setTimeout` in `useEffect`

### Card Expand Toggle (UI-02, D-02)

- Component: shadcn/ui `Collapsible`
- Each card expands independently (not accordion — multiple cards can be open simultaneously)
- Toggle button label: "Show details" (collapsed) / "Hide details" (expanded)
- Expanded content: charts section + comments section rendered together

### Direct URL Load (D-10)

- `/courses/142` must fetch data without prior search
- `CoursePage` reads `courseId` from `useParams()`, passes to `useProfessors(courseId)`
- No dependency on search page state

## State Management Summary

| State | Location | Why |
|-------|----------|-----|
| Search query string | `SearchPage` local state | Local to search input |
| Selected courseId | React Router URL param | Shareable via URL (D-08, D-10) |
| API data (professors, grades, comments) | TanStack Query cache | Caching, loading, error states (D-11) |
| Weight values (gpa, quality, difficulty, sentiment) | `CoursePage` state | Must flow to both sliders and list (Pitfall 7) |
| Computed/sorted professor list | `useMemo` in `CoursePage` | Derived from API data + weights |
| Cold-start banner visible | `useColdStartMessage` hook | Derived from `isLoading` + elapsed time |
| Card expand state | Each `ProfessorCard` local state | Independent per card (Collapsible) |
| Mobile sheet open | `CoursePage` state | Controls Sheet open/close |
