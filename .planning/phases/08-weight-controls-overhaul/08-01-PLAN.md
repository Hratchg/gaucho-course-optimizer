<objective>
Replace the four numeric weight sliders with four toggle checkboxes that auto-distribute weight equally among enabled factors. The professor ranking updates instantly on every toggle. Old slider component and its Slider UI dependency are removed.

Purpose: Sliders are confusing for students — toggles are simpler ("do I care about this factor?") and produce the same ranking quality via equal-weight distribution.
Output: WeightToggles.tsx component, updated scoring.ts with ToggleWeights type, updated CoursePage integration, full test coverage, cleanup of old slider code.
</objective>

    ```typescript
    export function normalizeToggles(toggles: ToggleWeights): Weights {
      const enabledCount = [toggles.gpa, toggles.quality, toggles.difficulty, toggles.sentiment]
        .filter(Boolean).length
      const share = enabledCount > 0 ? 1 / enabledCount : 0.25
      return {
        gpa: toggles.gpa ? share : 0,
        quality: toggles.quality ? share : 0,
        difficulty: toggles.difficulty ? share : 0,
        sentiment: toggles.sentiment ? share : 0,
      }
    }
    ```
