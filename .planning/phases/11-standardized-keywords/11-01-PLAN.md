<objective>
Add a curated tag vocabulary and mapping function to the backend so that raw NLP-extracted keywords are transformed into structured, frequency-filtered tags before being served by the API.

Purpose: Replace noisy single-word NLP extractions (e.g., "easy", "hard", "boring") with meaningful human-readable labels (e.g., "Easy Grader", "Tough Exams", "Dry Lectures") that students can actually use to evaluate professors. Frequency filtering (3+ reviews) ensures only genuinely representative attributes appear.

Output: Updated `dashboard/queries.py` with tag mapping, new `ProfessorTag` schema, updated API response shape, and comprehensive backend tests.
</objective>
