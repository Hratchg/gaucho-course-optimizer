## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, breadcrumb chevron padding |
| sm | 8px | Navbar link horizontal padding, breadcrumb item padding |
| md | 16px | Navbar horizontal edge padding, breadcrumb strip vertical padding |
| lg | 24px | Navbar total height (h-14 = 56px target — see exception), Sheet menu item spacing |
| xl | 32px | Sheet header padding-top |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Navbar height: 56px (h-14) — not a multiple of 4 at the token level, but 14 * 4 = 56px satisfies 4-point grid
- Mobile touch targets: minimum 44px height on all tappable nav links and hamburger button (WCAG 2.5.5)

## Interaction Contracts

### NavLink Active State

- Use `react-router-dom` `NavLink` with `className` callback: `({ isActive }) => isActive ? "font-bold text-white" : "text-white/80 hover:text-white"`
- Active detection is exact match for `/` and `/search`; pattern match for `/courses/:courseId`

### Sheet Open/Close

- Controlled via `open` / `onOpenChange` props on `Sheet` OR uncontrolled (Sheet manages state internally via SheetTrigger)
- On link click inside Sheet: call `setOpen(false)` before navigating, or use `SheetClose asChild` wrapping each `Link`
- Escape key and outside tap: handled by Radix Dialog primitive automatically

### Breadcrumb Route Detection

- Read current path with `useLocation()` from react-router-dom
- Map `/` → no breadcrumbs
- Map `/search` → `Home > Search`
- Map `/courses/:courseId` → `Home > Search > {courseId formatted}`
- `courseId` formatting: replace hyphens with spaces, uppercase (e.g., `cmpsc-130a` → `CMPSC 130A`)

### Deep Linking

- `vercel.json` already has SPA rewrites — no change needed
- All routes registered in `App.tsx` under Layout wrapper
- `BrowserRouter` already in `main.tsx` — no change needed
