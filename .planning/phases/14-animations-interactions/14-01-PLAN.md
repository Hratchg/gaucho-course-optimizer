# Plan 14-01: Micro-interaction Primitives and Animation Utilities

## Objective

Add five CSS-based micro-interaction primitives -- button press feedback, card hover elevation, page transitions, staggered list entrance, and skeleton shimmer -- as reusable utilities that respect prefers-reduced-motion. Pure CSS where possible, no heavy animation libraries.

## Context

- @frontend/src/index.css -- existing @keyframes shake, prefers-reduced-motion media query
- @frontend/src/components/ui/button.tsx -- shadcn Button, needs press feedback
- @frontend/src/components/SkeletonCard.tsx -- static skeleton, needs shimmer
- @frontend/src/components/ProfessorCard.tsx -- needs hover elevation + stagger delay
- @frontend/src/layouts/Layout.tsx -- page transition wrapper around Outlet
- @frontend/src/App.tsx -- route structure
- @frontend/src/pages/CoursePage.tsx -- renders ProfessorCard list (stagger source)

## Tasks

### Task 1: CSS animation utilities + SkeletonCard shimmer + Button press feedback
type: auto

**Actions:**
1. Add @keyframes to `index.css`:
   - `shimmer` -- gradient sweep left-to-right for skeleton loading
   - `stagger-fade-in` -- opacity 0->1, translateY 8px->0 for list entrance
2. Add utility classes to `index.css`:
   - `.btn-press` -- active:scale(0.97) + shadow reduction, 150ms transition
   - `.card-hover` -- hover shadow elevation lift, 200ms ease-out transition
   - `.shimmer` -- animated shimmer gradient overlay
   - `.stagger-in` -- applies stagger-fade-in animation with CSS custom property `--stagger-delay`
3. Update `SkeletonCard.tsx` -- replace static gray placeholders with shimmer animation
4. Update `button.tsx` -- add press feedback (active:scale-[0.97]) to base button styles

**Done criteria:**
- Skeleton cards show animated shimmer sweep
- Buttons scale to 0.97 on press with shadow change over 150ms
- All animations disabled under prefers-reduced-motion (covered by existing global rule)

### Task 2: ProfessorCard hover + stagger + page transitions
type: auto

**Actions:**
1. Update `ProfessorCard.tsx`:
   - Add card-hover class for shadow elevation on hover (200ms ease-out)
   - Accept optional `index` prop for stagger delay calculation
   - Apply stagger-in class with `--stagger-delay` set to `index * 40ms`
2. Update `CoursePage.tsx`:
   - Pass `index` prop to each ProfessorCard in the ranked list
3. Update `Layout.tsx`:
   - Add page transition wrapper (fade + subtle slide, 200ms) around the Outlet using a CSS transition approach with React key from location
4. Update `App.tsx` if needed to support location-keyed transitions

**Done criteria:**
- Professor cards lift on hover with elevated shadow (200ms ease-out)
- Professor cards animate in with staggered timing (40ms between each card)
- Page transitions show smooth fade + slide (200ms) between routes
- All animations disabled under prefers-reduced-motion
