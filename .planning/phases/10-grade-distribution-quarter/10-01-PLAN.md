   New interface:
   ```typescript
   interface GradeChartProps {
     quarters: GradeQuarter[]
     selectedQuarter: string  // "most-recent" | "all" | specific quarter string like "Fall 2024"
   }
   ```

   Filtering logic inside the component:
   - If `selectedQuarter === "all"`: sum across all quarters (current behavior — reduce all quarters)
   - If `selectedQuarter === "most-recent"`: use only the LAST element of the `quarters` array (the API returns quarters sorted by year ASC, quarter ASC, so last = most recent)
   - Otherwise (specific quarter string like `"Fall 2024"`): find the single quarter where `q.quarter === selectedQuarter` and display only that quarter's data

   Add a dynamic title above the chart using an `h4` element with classes `mb-2 text-sm font-semibold`:
   - For `"most-recent"`: display `"Grade Distribution — {actual quarter label}"` where the label comes from the last element's `.quarter` field (e.g., "Grade Distribution — Winter 2025")
   - For `"all"`: display `"Grade Distribution — All Quarters Combined"`
   - For a specific quarter: display `"Grade Distribution — {quarter}"` (e.g., "Grade Distribution — Fall 2024")

   IMPORTANT: Remove the hardcoded `<h4>` "Grade Distribution" heading from `ProfessorCard.tsx` `ExpandedCharts` in Task 2, since GradeChart now renders its own title.

   Keep the existing GRADE_KEYS, GRADE_LABELS, BarChart, ResponsiveContainer, Tooltip, XAxis, YAxis, Bar setup. Only change HOW data is computed (filter before summing) and add the title element above the ResponsiveContainer.
