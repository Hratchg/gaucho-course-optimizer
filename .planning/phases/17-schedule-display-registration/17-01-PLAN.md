# Phase 17 Plan 01: Schedule Display & Registration Context

Display "Teaching Next Quarter" badges with expandable section details, add quarter filtering, and show a registration countdown banner with pass time awareness.

## Context

- Phase 16 built the backend: ScheduledSection model, UCSB API client, schedule sync pipeline, nightly refresh
- The professors endpoint already returns `teaching_next_quarter` (bool) and `scheduled_sections` (ScheduledSectionResponse[]) per professor
- UCSBApiClient.fetch_current_quarter() exists for getting current quarter info
- Need a NEW /quarters/current backend endpoint for the registration countdown
- Design system: Royal Blue (#2563EB) + Snow (#FAFBFF) with Inter typography

## Tasks

### Task 1: Backend quarter endpoint + frontend types + API client
type="auto"

**Do:**
1. Create `api/routers/quarters.py` with `GET /quarters/current` endpoint that returns quarter name, next quarter code, and pass dates (pass1Begin, pass2Begin, pass3Begin) from UCSB Quarter Calendar API
2. Register quarters router in `api/main.py`
3. Update `frontend/src/types/api.ts` -- add `ScheduledSection` and `QuarterInfo` interfaces matching the backend response shapes
4. Update `frontend/src/lib/api.ts` -- add `fetchQuarterInfo()` function
5. Create `frontend/src/hooks/useQuarterInfo.ts` -- React Query hook for quarter info
6. Update `frontend/src/test/mswHandlers.ts` -- add scheduled_sections to mock professors, add /quarters/current mock handler

**Done when:**
- /quarters/current endpoint returns quarter info with pass dates
- Frontend types match backend schema
- MSW handlers mock the new data
- All existing tests pass

### Task 2: Professor card schedule display + quarter filter
type="auto"

**Do:**
1. Update `frontend/src/types/api.ts` -- add `teaching_next_quarter` and `scheduled_sections` fields to ProfessorRanking
2. Update `frontend/src/components/ProfessorCard.tsx`:
   - Add "Teaching Next Quarter" badge (blue outline variant, distinct from "Actively Teaching")
   - Add expandable section details showing day/time, building/room, enrolled/max_enroll
3. Update `frontend/src/pages/CoursePage.tsx`:
   - Add quarter filter buttons: "All" / "Next Quarter" / "Current Quarter" (using shadcn Button group)
   - "Next Quarter" filters to professors where teaching_next_quarter is true
   - "All" shows everyone (default)
   - Place filter in the sidebar alongside existing controls

**Done when:**
- "Teaching Next Quarter" badge appears on professor cards when applicable
- Section details are expandable (day/time, building/room, seats)
- Quarter filter toggles work and filter the professor list
- All tests pass

### Task 3: Registration countdown banner
type="auto"

**Do:**
1. Create `frontend/src/components/RegistrationBanner.tsx`:
   - Fetches quarter info via useQuarterInfo hook
   - Calculates days until next pass time (pass1Begin, pass2Begin, pass3Begin)
   - Shows "Pass N opens in X days" when within 7 days
   - Shows quarter name + link to GOLD (https://my.sa.ucsb.edu/gold/)
   - Dismissible with X button (state persisted via localStorage key "registration-banner-dismissed")
   - Auto-hides when no pass dates are within 7 days
   - Uses Royal Blue design tokens
2. Render `RegistrationBanner` in `frontend/src/layouts/Layout.tsx` below the Navbar
3. Verify all tests pass

**Done when:**
- Registration banner shows countdown when pass times are approaching
- Banner displays quarter name and GOLD link
- Banner is dismissible and stays dismissed via localStorage
- Banner auto-hides when no pass dates are imminent
- All tests pass
