## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Card internal element gaps, step circle inner padding |
| md | 16px | Card content padding, factor grid gap |
| lg | 24px | Hero subtext margin, step connector spacing |
| xl | 32px | Section heading bottom margin |
| 2xl | 48px | Factor card grid row gap on desktop |
| 3xl | 64px | Vertical padding between every major section |

Exceptions:
- Section separation: exactly 64px (py-16) between Hero, Score Breakdown, Factor Cards, Usage Guide, and Final CTA — no deviation. Source: 07-CONTEXT.md locked decision.
- Touch targets: minimum 44x44px on the final CTA button (WCAG 2.5.5).

## Interaction Contracts

### Score Bar

- Static diagram — no hover states, no click events, no animation.
- Purely visual and informational. Source: 07-CONTEXT.md ("Static diagram — Phase 8 introduces toggle controls, this is just explanation").

### Factor Cards

- Static content — no expand/collapse, no hover effects beyond default card ring.
- No interactive state needed.

### Usage Guide Steps

- Static — no click events on step circles or icons.
- Connector line renders on `md+` breakpoint, hidden on mobile.

### Final CTA Button

- `Link` wrapping shadcn `Button` component (same pattern as Phase 6 placeholder HomePage.tsx).
- `to="/search"` — React Router Link.
- Hover: `hover:bg-accent/90` (10% darker amber).
- Focus: inherits `outline-ring/50` from `@layer base` in index.css.

### Scroll Behavior

- Natural scroll — no sticky elements beyond the existing Navbar, no parallax, no animations.
- No scroll-triggered events. Source: 07-CONTEXT.md locked decision.

## Accessibility

| Requirement | Implementation |
|-------------|---------------|

| Heading hierarchy | h1 (hero) → h2 (section headings) → h3 (card titles) |
