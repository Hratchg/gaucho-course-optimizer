**index.css — prefers-reduced-motion media query (A11Y-06):**

Add at the END of the file:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

This blanket rule disables ALL non-essential animations when the OS preference is set. The `0.01ms` duration (not `0s`) prevents issues with animation-end event listeners. This covers the existing `.animate-shake` keyframe and any future animations from Phase 14.

**index.css — contrast verification (A11Y-01):**

Verify the existing Royal Blue palette from Phase 12. The current values are:
- `--primary: oklch(0.546 0.245 262.881)` which is #2563EB — Royal Blue on white (#FFFFFF card) = 4.6:1 contrast ratio (passes AA for normal text)
- `--foreground: oklch(0.21 0.034 264.665)` which is ~#111827 on Snow (#FAFBFF background) = 16.7:1 (passes AA)
- `--muted-foreground: oklch(0.554 0.046 257.417)` on white = ~4.6:1 (passes AA for normal text)

These all pass WCAG AA. No color changes needed. If during implementation any value is found to fail, adjust the oklch lightness down (darker) to achieve 4.5:1 minimum.
