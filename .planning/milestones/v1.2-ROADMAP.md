# Milestone v1.2: Data Quality & Insights (COMPLETED 2026-04-08)

v1.2 surfaced more meaningful, actionable information on professor cards — active teaching status, recent grade distributions, and curated keyword tags — so students make better-informed decisions. Three vertical-slice phases, each delivering backend + frontend as a complete feature.

## Key Accomplishments

1. **"Actively Teaching" badges** — Professor cards now show an "Actively Teaching" teal pill badge for professors who taught the course 3+ times in the past 3 years, with a filter toggle and collapsible quarter history
2. **Per-quarter grade distributions** — Grade chart defaults to the most recent quarter's data instead of all-time aggregate, with a dropdown to select any specific quarter or view combined history
3. **Standardized keyword tags** — Raw NLP-extracted keywords replaced with a curated 15-tag vocabulary (e.g., "Easy Grader", "Tough Exams", "Engaging Lectures"), frequency-filtered to 3+ reviews, with hover tooltips showing review counts
4. **Full-stack delivery** — Each feature was delivered as a vertical slice with backend (FastAPI/SQLAlchemy) and frontend (React/TypeScript) changes, plus comprehensive test coverage
